# Frontend v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first usable version of the Pynance web app — Dashboard, Transactions, and Categories pages — against the existing FastAPI backend, with a clean, modern, light fintech look.

**Architecture:** Vite + React SPA in `frontend/`, consuming the backend JSON API (dev via Vite proxy to `localhost:8000`). TanStack Query owns server state; React Router owns navigation; no global client state library. Each page is a route; shared UI comes from shadcn/ui components; the design is token-driven (Tailwind CSS variables) so the whole look can be re-themed later without touching page code.

**Tech Stack:** Vite 7, React 19, TypeScript (strict), Tailwind CSS v4, shadcn/ui, TanStack Query v5, React Router v7, Recharts (via shadcn charts).

**Style guideline (high-level, not mandatory):** clean, modern, uncluttered; light mode; generous white space; soft shadows, subtle borders, smooth rounded corners; sans-serif for UI text (Inter); **JetBrains Mono for all numbers/financial figures**. Income = emerald, expense = rose/red. Every task ends with a **checkpoint**: build + lint green, then human review before the next task.

**API contract (existing backend):**

| Method/Path | Request | Response |
|---|---|---|
| `POST /api/categories` | `{name, transaction_type}` | 201 Category |
| `GET /api/categories` | — | `Category[]` |
| `DELETE /api/categories/{id}` | — | 204 *(new backend endpoint — backend exercise, see Task 5)* |
| `POST /api/transactions` | `{transaction_type, amount, category_id, description, occurred_on}` | 201 Transaction |
| `GET /api/transactions` | — | `Transaction[]` |
| `GET /api/transactions/{id}` | — | Transaction |
| `PATCH /api/transactions/{id}` | partial fields | Transaction |
| `DELETE /api/transactions/{id}` | — | 204 |
| `GET /api/transactions/summary?year=&month=` | — | `{income, expense}` |
| `GET /api/transactions/spending-by-category?transaction_type=&year=&month=` | — | `[{category_id, category_name, amount}]` |

Category = `{id, name, transaction_type: "income"|"expense", created_at}`; Transaction = `{id, transaction_type, amount: "12.34", category_id, description, occurred_on: "2026-08-05", created_at}`. Amounts come back as decimal **strings**. Enum values are lowercase.

- [ ] **Step 1: Fetch wrapper**

`frontend/src/lib/api.ts`:

```ts
export class ApiError extends Error {
  status: number
  constructor(status: number, message: string) {
    super(message)
    this.status = status
  }
}

async function request<T>(path: string, init?: RequestInit): Promise<T> {
  const response = await fetch(path, {
    headers: { "Content-Type": "application/json" },
    ...init,
  })
  if (!response.ok) {
    const body = await response.json().catch(() => null)
    throw new ApiError(response.status, body?.detail ?? response.statusText)
  }
  if (response.status === 204) return undefined as T
  return response.json() as Promise<T>
}

export const api = {
  categories: {
    list: () => request<import("@/types/api").Category[]>("/api/categories"),
    create: (data: { name: string; transaction_type: string }) =>
      request<import("@/types/api").Category>("/api/categories", {
        method: "POST",
        body: JSON.stringify(data),
      }),
    remove: (id: number) =>
      request<void>(`/api/categories/${id}`, { method: "DELETE" }),
  },
  transactions: {
    list: () => request<import("@/types/api").Transaction[]>("/api/transactions"),
    create: (data: unknown) =>
      request<import("@/types/api").Transaction>("/api/transactions", {
        method: "POST",
        body: JSON.stringify(data),
      }),
    update: (id: number, data: unknown) =>
      request<import("@/types/api").Transaction>(`/api/transactions/${id}`, {
        method: "PATCH",
        body: JSON.stringify(data),
      }),
    remove: (id: number) =>
      request<void>(`/api/transactions/${id}`, { method: "DELETE" }),
    summary: (year: number, month: number) =>
      request<import("@/types/api").MonthlySummary>(
        `/api/transactions/summary?year=${year}&month=${month}`,
      ),
    spendingByCategory: (type: string, year: number, month: number) =>
      request<import("@/types/api").SpendingRow[]>(
        `/api/transactions/spending-by-category?transaction_type=${type}&year=${year}&month=${month}`,
      ),
  },
}
```

- [ ] **Step 2: Money component — the style centerpiece**

`frontend/src/components/money.tsx`:

```tsx
import { cn } from "@/lib/utils"

const formatter = new Intl.NumberFormat("en-US", {
  style: "currency",
  currency: "EUR",
  minimumFractionDigits: 2,
})

interface MoneyProps {
  value: string
  className?: string
}

export function Money({ value, className }: MoneyProps) {
  const amount = Number(value)
  const sign = amount > 0 ? "+" : ""
  return (
    <span className={cn("font-numeric tabular-nums", className)}>
      {sign}
      {formatter.format(amount)}
    </span>
  )
}
```
